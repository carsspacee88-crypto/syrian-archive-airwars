نشر الأرشيف على GitHub Pages
==============================

1. افتح Settings ثم Pages في المستودع.
2. اختر GitHub Actions في خانة Source.
3. شغّل سير العمل «نشر الأرشيف على GitHub Pages» أو ادفع تغييرًا إلى main.

يعيد سير العمل تكوين الحزمة التاريخية ويتحقق من SHA-256، ثم يولّد تقارير
الجمع والخريطة، ويبني صفحة المنهجية ومنشأ الحالات والبحث المحلي، ويفحص
8,114 صفحة وملفات JSON والروابط الداخلية والمسارات النسبية. لا يُرفع artifact
إلا إذا كان index.html و.nojekyll في الجذر ولم توجد أخطاء تحقق حرجة.

الموقع:
https://carsspacee88-crypto.github.io/syrian-archive-airwars/

لا يحتاج الموقع إلى قاعدة بيانات أو PHP أو Node.js أو خادم خلفي.
لتشغيل دفعة جمع جديدة استخدم سير العمل «جمع بيانات Airwars» من تبويب Actions.
