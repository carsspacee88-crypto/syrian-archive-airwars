# خطة مستقبلية لحفظ الوسائط — غير منفذة

هذه وثيقة تخطيط فقط. يمنع الإصدار الحالي تنزيل الصور والفيديوهات أو نسخها إلى المستودع.

## الحجم المتوقع

تحتوي اللقطة التاريخية على 22,119 سجل وسائط، لكن عدد الملفات الفريدة لم يُقَس بعد وقد يشمل السجل عدة أحجام للرابط نفسه. إذا كان متوسط الأصل بين 1 و5 ميغابايت، فالنطاق النظري قبل إزالة التكرار يقارب 22–111 غيغابايت. وإذا كان متوسط المصغّر 200 كيلوبايت، فقد تضيف المصغرات نحو 4.4 غيغابايت. هذه تقديرات سيناريو وليست قياسًا.

## خط العمل المقترح

1. استخراج قائمة URL مستقلة مع الحادثة والمصدر والتسمية والحساسية وحقوق النشر.
2. تنفيذ طلب `HEAD` أو طلب محدود لقياس النوع والحجم من دون تنزيل شامل.
3. إنشاء قائمة سماح لأنواع MIME وحد أقصى للحجم، ومنع HTML والملفات التنفيذية.
4. تنزيل إلى مساحة حجر منفصلة عن Git، ثم حساب SHA-256 وBLAKE3 قبل النشر.
5. إزالة التكرار حسب البصمة الثنائية، مع إبقاء علاقة كل URL وحادثة بالملف المشترك.
6. تخزين الأصل في مخزن كائنات أو أرشيف مؤسسي بإصدارات واحتفاظ، وليس في مستودع Git الرئيسي.
7. إنشاء مصغرات WebP/AVIF صغيرة بعد الفحص، مع إبقاء الأصل دون تعديل.
8. حفظ manifest يضم البصمة والحجم وMIME ووقت الجمع والرابط الأصلي وحقوق النشر والإسناد.

## خيارات التخزين

- مخزن كائنات متوافق مع S3 مع versioning وObject Lock عند الحاجة.
- مخزن أرشيفي بارد للنسخ الأصلية، وطبقة توصيل منفصلة للمصغرات.
- نسخة تحقق ثانية في جهة أو منطقة مستقلة.

يجب فصل التخزين عن GitHub Pages ومراعاة حدود النقل والتكلفة وسياسات الإزالة القانونية.

## المحتوى الحساس والحقوق

- لا تظهر الوسائط الصادمة افتراضيًا؛ يتطلب العرض قرارًا صريحًا ويُحترم تفضيل تقليل الحركة.
- لا تُنشأ معاينات آلية للفيديو الصادم من دون مراجعة.
- تحفظ بيانات الناشر، المؤلف، تاريخ النشر، الترخيص إن وجد، ورابط طلب الإزالة.
- لا يُفترض أن الإتاحة العامة تعني الإذن بإعادة النشر. يلزم تقييم قانوني وحقوقي قبل النسخ المحلي.
- أسماء الملفات الداخلية محايدة ومشتقة من البصمة، ولا تتضمن أسماء ضحايا.

## شرط البدء

لا يبدأ التنفيذ قبل إنتاج تقرير قياس فعلي لعدد الروابط الفريدة والأحجام، وتحديد ميزانية التخزين، وسياسة الحقوق والإزالة، وموافقة صاحب المشروع على نطاق التنزيل.
