# Airwars HTTP 403 incident

## Finding

Current direct Airwars endpoint/live-page attempts for the canonical Syria incident set are blocked by HTTP 403 or the host circuit opened from repeated HTTP 403 evidence. Archived-copy recovery is a separate origin and never changes the direct result.

## Representation

Each incident retains both:

- `record_origin_status`: historical/local/normalized, or mixed with a legitimate archived copy;
- `direct_verification_status`: `BLOCKED_HTTP_403` for current direct attempts.

No 403 is counted as fetched, verified, collected, archived, preserved source text, or completed source page. The structural skeleton can still be complete because lawful local/historical data supplies the incident record. External sources may remain blocked while their reference, raw URL, relationship, provenance, attempts, and exact content status remain complete.

## Lawful recovery boundary

Allowed paths are existing local records/raw/cache, Git and prior releases, official public datasets/APIs/downloads, public archive snapshots, existing Wayback URLs, normal browser-rendered public access, and manual import. Authentication, CAPTCHA, private permissions, and security controls are never bypassed.
