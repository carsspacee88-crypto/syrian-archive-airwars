# الأرشيف السوري — بيانات Airwars

واجهة عربية ثابتة مستقلة لعرض الحوادث الموثقة المتعلقة بسوريا اعتمادًا على البيانات المجمعة من Airwars.

> هذا المشروع مستقل وغير تابع رسميًا لـ Airwars. قد تتضمن بعض الصفحات معلومات أو روابط إلى محتوى مؤلم.

يتضمن الإصدار الحالي 8,114 حادثة، وصفحة مستقلة لكل حادثة، ومصادر ووسائط وضحايا وروابط أرشيفية متاحة في ملف البيانات الأصلي.

سيُنشر الموقع تلقائيًا عبر GitHub Pages من خلال GitHub Actions.
