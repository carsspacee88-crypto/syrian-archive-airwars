# الأرشيف السوري — بيانات Airwars

واجهة عربية ثابتة ومستقلة لعرض الحوادث الموثقة المتعلقة بسوريا اعتمادًا على البيانات المجمعة من Airwars.

> هذا المشروع مستقل وغير تابع رسميًا لـ Airwars. قد تتضمن بعض الصفحات معلومات أو روابط إلى محتوى مؤلم.

## محتوى الإصدار

- 8,114 حادثة.
- 8,114 صفحة حالة مستقلة.
- 50,326 سجل مصدر.
- 22,119 سجل وسائط.
- 20,045 سجل ضحية.
- 6,681 نقطة صالحة على الخريطة.

الموقع عربي بالكامل، من اليمين إلى اليسار، ولا ينزّل الصور أو الفيديوهات؛ بل يستخدم الروابط الخارجية المسجلة في الأرشيف.

## آلية النشر

نظرًا إلى أن الموقع يحتوي على أكثر من 16 ألف ملف ثابت، حُفظت حزمة الموقع الموثقة في أجزاء داخل `site-package/`. يقوم GitHub Actions تلقائيًا بما يلي:

1. دمج الأجزاء في ملف ZIP واحد.
2. التحقق من بصمة SHA-256.
3. فك الموقع إلى مجلد مؤقت.
4. نشر الملفات على GitHub Pages.

الحزمة الأصلية:

- الحجم: `81,855,462` بايت.
- SHA-256: `9f35a90d92f9fb0334cb61ffd8434aac03fd0ee61622908a11923dac40da35f3`.
- عدد الملفات: `16,326`.

لا يحتاج الموقع إلى PHP أو MySQL أو Node.js أو خادم خلفي.
